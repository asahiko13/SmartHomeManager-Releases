# SmartHome Manager – Releases

Dieses Repository enthält ausschließlich die fertigen, signierten APK-Dateien von SmartHome Manager als [GitHub Releases](../../releases) – der Quellcode liegt in einem privaten Repository.

## Installation

1. Neuestes Release öffnen: [Releases](../../releases/latest)
2. Die `.apk`-Datei herunterladen und öffnen (Installation aus unbekannten Quellen ggf. einmalig erlauben)

Die App selbst prüft beim Start automatisch, ob eine neuere Version verfügbar ist, und zeigt dir dann die Release-Notizen an.
