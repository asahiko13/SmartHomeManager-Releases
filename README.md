# SmartHome Manager – Releases

Dieses Repository enthält ausschließlich die fertigen, signierten APK-Dateien von **SmartHome Manager** als [GitHub Releases](../../releases) – der Quellcode liegt in einem privaten Repository.

SmartHome Manager ist eine private, nicht im Play Store erhältliche Android-App zur Dokumentation der eigenen Smart-Home-Geräte: Räume, Gerätetypen, Protokolle, Matter-Codes, IP-Adressen, Grundriss-Positionen und mehr – inklusive optionalem, rein lesendem Home-Assistant-Abgleich, xlsx-Import/-Export und vollständigem Backup.

## Installation

1. Neuestes Release öffnen: **[Releases](../../releases/latest)**
2. Die `.apk`-Datei herunterladen und öffnen (Installation aus unbekannten Quellen ggf. einmalig erlauben)

Die App selbst prüft beim Start automatisch, ob eine neuere Version verfügbar ist, und zeigt dir dann die Release-Notizen an – ein erneuter Besuch hier ist danach meist nicht mehr nötig.
